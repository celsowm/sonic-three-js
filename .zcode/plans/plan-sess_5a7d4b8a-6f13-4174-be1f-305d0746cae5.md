# Plan: Real 3D textured stages — no more flat canvas planes, gameplay stays 2D

## Goal
Replace every flat-plane / canvas-painted stage visual with **real 3D geometry and real texture asset files**: extruded 3D terrain (grass top surface receding into depth, textured dirt faces), the Blender-built 3D GLB props and background (fixed + regenerated), and a straight-on perspective 2.5D camera (user's choice). Delete the canvas texture module and flat runtime art entirely. Physics, collision, input, HUD are untouched — all verified projection-agnostic.

## 1. Real texture assets (authored PNG files, no canvas at runtime)
New `scripts/generate-green-hill-textures.mjs` (Node, zero new deps — PNG encoded via `node:zlib`, same hand-rolled-binary pattern as `create-green-hill-palm-tree-asset.mjs`; deterministic, output committed to repo). npm script `assets:textures:green-hill`. Writes to `assets/textures/green-hill/` + metadata.json:
- `dirt-checker.png` 256×256 — classic checker `#D86C00`/`#6C2400` with subtle deterministic per-square shading so it reads as a real texture
- `dirt-band.png` 256×64 — dark band checker `#6C2400`/`#240000`
- `grass-top.png` 256×256 — `#48B400` with `#90FC00`/`#006C00` speckle streaks (for the depth-visible top surface)
- `grass-front.png` 256×64 — dappled grass rim with dark boundary

## 2. Straight-on perspective camera (2.5D)
- Use the existing dead `cameraMode: 'perspective'` branch in `Renderer.ts`: fov default 40, camera at `z = (visibleHeight/2)/tan(fov/2)` so the z=0 gameplay plane keeps the exact same 96-unit framing (art calibration preserved). Recompute distance in `setVisibleHeight`/resize. Default stays `'side-scroller'` (camera tests pin it).
- `CameraDefinition` gains `mode?: 'side-scroller' | 'perspective'` and `fov?`. Since the Renderer is built at `new Stage()` (before level load), `examples/demo.ts` forwards `level.camera.mode/fov` into Stage/Engine options; `LevelLoader` still applies `visibleHeight`.
- `greenHillAct1.camera`: `mode: 'perspective', fov: 40`. physicsPlayground stays orthographic.

## 3. LevelLoader: texture library, progress, node picking
- `StageThemeDefinition.textures?: Record<string, { url: string }>`.
- Texture loading: optional injected `THREE.TextureLoader` (mirrors the GLTFLoader injection used by tests), URL-keyed `textureCache`, wrapped in `track()` so `totalLoads` counts textures (LoadingScreen handles any total). Configure RepeatWrapping + SRGBColorSpace + anisotropy 4.
- `load()` awaits theme textures before terrain creation; builders receive loaded `THREE.Texture`s.
- `ModelDecorationDefinition.node?: string` — `addModelDecoration` clones the `getObjectByName(node)` subtree, so one props GLB yields many decorations.

## 4. New 3D terrain builder `src/level/greenHillTerrain3D.ts`
Replaces the green-hill branch of `createTerrain` (custom BufferGeometry, world-unit UVs like today):
- **Open paths**: per-segment strips → dirt front face (z≈−6), dark band, grass front rim, **grass top surface extending back to z≈−60** (the perspective-visible 3D top), end caps, and sparse 3D grass blades (cones) along the rim. Lit `MeshLambertMaterial`.
- **Closed paths**: extruded ring (ExtrudeGeometry of the ring shape) with textured front + rim blades.
- **Solid platform**: textured box body + grass top slab + blades.
- Depth budget: terrain z ∈ [−60, −6]; foreground props move onto the top surface (z≈−20…−40); palms/loop z tuned during verification.

## 5. Props + background: fix and wire the Blender GLBs
- Fix the axis bug in `generate-green-hill-environment.py` `make_props()`/`make_background()` (heights currently in Blender's Y slot while primitives axis on Z — palms/flowers/hills export with broken verticality).
- Regenerate with `npm run assets:elements:green-hill` (Blender exists on this machine; fallback: post-fix node transforms with an `@gltf-transform/core` script).
- Wire into `greenHillAct1.ts` via `node:` picking: 3D flowers replace flat sunflowers ×9, 3D rock ×5, totem ×2, sign ×2, props-GLB palms replace the 2 flat runtime palms (keep the 5 SA2 palm GLBs); background GLB (ocean/hills/clouds) replaces the 4 flat backdrops, instanced/scaled to cover level width.
- **Delete** `greenHillRuntimeArt.ts`, `greenHillTextures.ts`, the `RuntimeDecorationDefinition` type, and their exports.

## 6. Lighting polish
Tune ambient/directional for lit Lambert terrain (front faces stay bright, top surfaces shade); optional fill light. No shadows (out of scope).
